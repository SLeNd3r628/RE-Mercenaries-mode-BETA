# RE Mercenaries Gamemode - Public Beta

**_Resident Evil Mercenaries survival action mixed with some elements from RE Raid mode._**

**_Survive waves of enemies, rack up combos, chase high scores and S-ranks in fast-paced rounds. Built from the ground up for gmod._**

## Key Features

- **Authentic Mercenaries Gameplay**: Score, combo, rank, time extensions, and RE-style pickups (Green Herbs, ammo, time limit).
- **Dynamic Spawning**: Smart navmesh + fallback spawning. Elite enemies that scale with total kills.
- **Customization**: Full loadout picker, playermodel + hands/skin/bodygroup selector, player color.
- **Themes**: Resident Evil 4 enemies (default), Half-Life 2 enemies, and future custom NPC support.
- **Extra**: Animated results screen, floating damage numbers, kill feed, elite alerts, combo popups, health bars, and dedicated music system.

## Beta Status

**_This is an open public beta — still in active development and also my very first gamemode I've ever made. Expect bugs, missing assets, and balance tweaks. Feedback and bug reports are very welcome!_**

## Installation

1. Subscribe via Steam Workshop or download the build from here and place it manually in your gamemodes folder
2. (if manually installed, if not then skip this step) subscribe to https://steamcommunity.com/sharedfiles/filedetails/?id=3767567317 to get the needed content files and put in your addons folder
3. Open the game and start a map in singleplayer with the gamemode selected.
4. (Recommended) Run `nav_generate` on maps without navmeshes.
